# 📖 About This Repository

This repository serves as a documentation and reference resource for Microsoft Activation Scripts (MAS).

It is intended to provide an organized overview of the supported activation methods, related technologies, and general reference information for educational and documentation purposes.

---

# 📚 Topics Covered

This documentation includes information about:

- HWID
- Ohook
- TSforge
- Online KMS
- Windows Activation
- Microsoft Office Activation
- Extended Security Updates (ESU)
